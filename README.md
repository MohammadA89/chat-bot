# دستیار هوشمند

یک چت‌بات وب حرفه‌ای و کاملاً راست‌چین (RTL) که به هر سرویس هوش مصنوعی سازگار با **OpenAI** یا **Anthropic** متصل می‌شود. کاربر در گام اول Base URL و کلید API خود را وارد می‌کند، لیست مدل‌ها به‌صورت خودکار از همان سرویس خوانده می‌شود، و گفتگوها در مرورگر ذخیره می‌مانند.

## امکانات

| | |
| --- | --- |
| **اتصال در گام اول** | دریافت Base URL و کلید API با اعتبارسنجی زنده پیش از ورود به محیط چت |
| **دو پروتکل** | `POST /chat/completions` (OpenAI) و `POST /messages` (Anthropic) |
| **انتخاب مدل** | لیست مدل‌ها از `GET /models` خوانده می‌شود، با جستجو و بارگیری مجدد |
| **پاسخ لحظه‌ای** | نمایش استریمی متن به‌همراه امکان توقف تولید در میانه‌ی کار |
| **خروجی حرفه‌ای** | مارک‌داون کامل، جدول، بلوک کد با هایلایت و دکمه‌ی کپی، و فرمول‌های ریاضی LaTeX |
| **سابقه‌ی گفتگو** | ذخیره‌ی خودکار، گروه‌بندی زمانی، جستجو، تغییر نام و حذف |
| **زنجیره‌ی استدلال** | نمایش بخش reasoning در مدل‌هایی که آن را برمی‌گردانند |
| **ظاهر** | حالت تیره و روشن، طراحی واکنش‌گرا، و فونت وزیرمتن |

## اجرا

</div>

```bash
npm install
npm run dev
```

<div dir="rtl">

سپس در صفحه‌ی نخست:

1. نوع سرویس را انتخاب کنید (**OpenAI سازگار** یا **Anthropic سازگار**).
2. `Base URL` را وارد کنید — اگر انتهای آن `/v1` نباشد، خودکار اضافه می‌شود.
3. کلید API را وارد کنید و روی **اتصال و دریافت مدل‌ها** بزنید.

اطلاعات اتصال فقط در `localStorage` همان مرورگر ذخیره می‌شود و به هیچ سرور دیگری ارسال نمی‌گردد.

## سرور آزمایشی

برای بررسی محیط بدون نیاز به سرویس واقعی، یک سرور ماک از هر دو پروتکل پشتیبانی می‌کند:

</div>

```bash
npm run mock       # http://localhost:8787/v1  (هر کلیدی پذیرفته می‌شود)
```

## نکته‌ی CORS

این اپلیکیشن تماماً در مرورگر اجرا می‌شود و مستقیماً با سرویس شما حرف می‌زند. اگر با خطای «اتصال به سرور برقرار نشد» روبه‌رو شدید، معمولاً یعنی سرویس شما هدرهای CORS را برای دامنه‌ی این صفحه باز نکرده است؛ در این حالت باید CORS را روی سرویس فعال کنید یا اپ را پشت یک پراکسی هم‌دامنه قرار دهید.

## ساختار پروژه

</div>

```text
src/
├── App.tsx               چیدمان اصلی، مدیریت وضعیت و جریان ارسال پیام
├── types.ts              مدل داده‌ها و تنظیمات پیش‌فرض
├── lib/
│   ├── api.ts            لایه‌ی ارتباط با API و پارسر SSE برای هر دو پروتکل
│   ├── storage.ts        ذخیره‌سازی در localStorage
│   ├── highlighter.ts    هایلایت کد با مجموعه‌ی محدود و سبک زبان‌ها
│   ├── languages.ts      زبان‌های ثبت‌شده در highlight.js
│   └── utils.ts          کمک‌تابع‌ها: تاریخ فارسی، گروه‌بندی، شناسه‌ها
├── components/
│   ├── Setup.tsx         صفحه‌ی اتصال (گام اول)
│   ├── Sidebar.tsx       سابقه‌ی گفتگوها
│   ├── ModelPicker.tsx   انتخاب مدل
│   ├── ChatMessage.tsx   نمایش پیام
│   ├── Markdown.tsx      رندر مارک‌داون، کد و ریاضی
│   ├── Composer.tsx      کادر نوشتن پیام
│   ├── SettingsModal.tsx تنظیمات
│   └── Welcome.tsx       صفحه‌ی خوش‌آمد
└── scripts/mock-api.mjs  سرور آزمایشی هر دو پروتکل
```
